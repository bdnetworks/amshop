# **App Name**: ShopSwift

## Core Features:

- Product Catalog: Product listing with images, descriptions, and prices.
- Product Upload: Easy product upload form with fields for name, description, images, and price.
- Shopping Cart: Shopping cart functionality to add and manage selected products.
- Checkout Page: Streamlined checkout process with order summary and submission.
- Order Notification: Email notification to the admin's Gmail upon order submission.
- AI Product Descriptions: AI-powered product description tool that can enhance basic descriptions with persuasive language based on similar successful listings. The AI model will be a tool in helping to generate the description.

## Style Guidelines:

- Primary color: Muted purple (#8E44AD) to convey sophistication and trust in a retail environment.
- Background color: Light gray (#F0F0F0), providing a clean, neutral backdrop.
- Accent color: Soft lavender (#D0B4DE) to highlight interactive elements and CTAs without overpowering the user experience.
- Body and headline font: 'Inter', a grotesque-style sans-serif font that combines modern aesthetics with readability.
- Use modern, minimalist icons for categories, cart, and user actions.
- Clean, grid-based layout for product listings and a straightforward checkout process, similar to https://nextjs-two-navy-66.vercel.app/.
